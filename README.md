# AI Claims Detection — Healthcare COB Use Case

## 1. Context
The project explored an AI-driven system to identify mis-coordination of benefits (COB) in healthcare claims — a billion-dollar opportunity. The goal: help payers detect when another insurer should be responsible for paying the claim.

## 2. Problem
COB is often missed due to:
- fragmented data  
- unstructured documents  
- outdated or missing policy metadata  
- manual investigations  

This leads to wrong payments and multi-million-dollar annual leakage.

## 3. My Role
I led:
- Product definition  
- Discovery with payers and TPAs  
- Data validation strategy  
- AI-assisted detection rules  
- Integration patterns with Tapestry  
- Roadmap for MVP → Pilot

## 4. Solution Overview
- Ingest structured claims + unstructured docs  
- Apply rules + AI similarity checks  
- Surface “probabilities of mis-coordination”  
- Generate Evidence Pack (explanation layer)  
- Export into payer workflows or BI dashboards  

## 5. Key Decisions
- Use AI only for candidate detection, NOT automated adjudication  
- Define evidence-based explanations for trust  
- Build “Partner Vaults” integration via Tapestry  
- Keep PHI masked or tokenized during model evaluation

## 6. Impact
- Identified potential 7-figure savings for payer clients  
- Validated a scalable AI use case for Tapestry  
- Defined a productizable claims engine architecture
